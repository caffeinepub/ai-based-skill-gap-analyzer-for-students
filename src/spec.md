# Specification

## Summary
**Goal:** Transform the application's visual theme from warm education-focused colors to a professional modern aesthetic suitable for a SaaS platform.

**Planned changes:**
- Update global CSS configuration to use a professional color palette with navy (#1e3a5f), charcoal (#2c2c2c), slate grays (#64748b, #475569), and white (#ffffff) in OKLCH format for both light and dark modes
- Update Tailwind configuration to align with the new professional color scheme
- Refine typography across the application with clear visual hierarchy using appropriate font sizes, weights, and line heights
- Apply professional theme styling to Layout component including navigation, header, and footer
- Update HomePage with polished hero section, clean feature cards, and improved visual hierarchy
- Update AnalysisFlow component with professional styling for resume upload and job role selection steps
- Update AnalysisDashboard with professional theme for data visualization cards and metrics display
- Update chart components (SkillMatchChart, SkillCategoryChart, ProficiencyGapChart) to use professional color palette for data visualization
- Update GapAnalysisResults component with professional card styling and refined badges
- Update RecommendationsDisplay component with clean cards and refined typography
- Update AdminPanel with professional admin interface styling including refined form controls and job role cards
- Update JobRoleForm with professional form styling and clean skill management interface
- Update ResumeUpload component with professional drag-and-drop zone and upload progress styling
- Update JobRoleSelector with professional card styling for job role options and refined skill badges
- Update all button components to use consistent professional button design system with navy primary buttons and charcoal secondary buttons
- Update ProfileSetupModal with professional modal styling and refined form fields

**User-visible outcome:** The entire application displays a clean, professional modern aesthetic with navy, charcoal, and slate colors throughout all pages, forms, dashboards, and admin interfaces, conveying trustworthiness and expertise suitable for a business SaaS platform.
